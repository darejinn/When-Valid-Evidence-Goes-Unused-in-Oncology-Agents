\section*{Numbering and materials}
For the archival body, PDF page equals original printed page minus eight.
The addendum uses printed pages S1 onward. References to main sections and
figures refer to the submitted manuscript; compact and archival table numbering
can differ.

\textbf{Finding the paper's references.} The paper uses condensed appendices;
this PDF retains the expanded numbering. For example, paper Table 6 corresponds
to Table 23 here (PDF page 23), and paper Table 8 to Table 31 (PDF page 28).
Section S6 (PDF page 37 onward) and the repository README map the paper's
references to the relevant sections, tables, and pages.

\textbf{File availability.} Paths beginning with \texttt{versions/} or
\texttt{analysis\_inputs/}, and the directory map in original Table 13, refer to
the research workspace. Those directories and the separate companion report
are not included in this repository. The relevant methods and disclosed prompts
can be read in this PDF; the original executable files are not supplied.

The repository contains the original supplement in \texttt{archive/}, the
addendum PDF and LaTeX sources, 90 pairs of outcome labels, and scripts to
recompute those counts and build the PDFs. The labels do not support independent
response scoring or reproduction of the reported bootstrap intervals. Licensed
candidate text, full transcripts, and private reader forms are not distributed.
